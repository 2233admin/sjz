SJZ 抢购控制台 · 使用说明
========================

双击 start.bat，浏览器会自动打开 http://127.0.0.1:8777
关掉那个黑窗口就是退出。


一、第一次用：把界面认下来
--------------------------
1. 打开游戏，停在「商品详情」页面，让购买按钮和商品名都露出来。

2. 控制台左边是实时画面，右边四个标签页。先进「框选」。

3. 选「购买」，在左边画面上拖一个框，框住购买按钮。
   选「确认」，拖框框住确认弹窗里那个「确认」按钮。
   选「商品名」，拖框框住商品名称那一行文字（想自动认商品就框）。

4. 点「把框内画面存成模板」：
   先切到「购买」，让按钮显示"公示中"这类占位状态 → 存一次 buy 模板。
   等弹窗出现时再框/存一次 confirm 模板。

   模板 = 你要盯的那块像素长什么样。程序靠它判断按钮有没有变。

5. 点「读一次商品名 / 价格」验证 OCR 能不能认出来。
   认不出来就重框商品名区域，框紧一点、只框字。


二、加任务
----------
单条：填商品名 → 填开卖时间 → 「加入队列」。
批量：一行一个商品名 → 填首条开卖时间 → 填相邻间隔 → 「批量加入队列」。
      间隔填 0 就是同一个时间点开卖。

开卖时间留空 = 手动触发，点「实战开抢」后立刻开抢。

任务卡上的「用当前画面重截模板」：如果你已经把界面切到那个商品，
点这个就用当前画面给这条任务单独存一套模板，比全局模板更准。


三、砖皮页（赛季 / 稀有度 / 成色）
----------------------------------
右边第四个标签「砖皮」是一张本地知识库，11 个赛季的砖皮都在里面：

  S1 起源 · S2 聚变 · S3 焰火 · S4 黑夜之子 · S5 破壁 · S6 烈火冲天
  S7 阿萨拉 · S8 蝶变时刻 · S9 回声 · S10 裂变 · S11 群星

用法一：把游戏里那一行字粘进输入框（或点「读游戏里那一行」直接 OCR），
        下面立刻告诉你这是哪个赛季、哪把枪、当期还是往期、成色多少。
        例：输入「M7 棱镜攻势 极品S」→ S6 烈火冲天 · 往期 · 极品S。

用法二：认准了以后点「当成商品名加到队列」，商品名和别名自动填好，
        直接进任务队列，不用手打。

稀有度分三层，别混着看：
  品阶  普通(绿) < 稀有(蓝) < 史诗(紫) < 传说(橙) < 典藏(红金)
        「典藏」就是砖皮，最高一档，只能开曼德尔砖出。
  做工  极品（完整动态特效：金色曳光弹、电镀变色、击杀计数、专属语音）
        优品（特效简化：蓝色曳光弹，无动态纹理和语音）
  成色  S 典藏级 ≤0.4 · A 0.4~1.25 · B 1.25~2.5 · C >2.5
        掉落时定死，不会因为用得久变差。

所以排序是：极品 S（隐藏模板）> 极品 S > 极品 A > 优品 S > … > C 级。
「当期」和「往期」也影响价值：超过 5 个赛季的砖进入稀有掉落，存量少。

两个容易踩的坑（知识库里也写了）：
  · S10 的砖皮是「群星 - AKM」，不是网上攻略写的「SR-3M 深渊之核」。
  · 「群星」一名两用：S10 的砖皮叫群星，S11 的赛季名也叫群星。
    认砖皮看武器型号：群星 = AKM，疾光魅影 = MK4。


四、开抢
--------
先「演练整队」——只识别、不点鼠标，确认它能认出按钮变化。
确认没问题再点「实战开抢整队」（要点两次）。


五、几个关键设定
----------------
触发方式（框选页底部）
  等按钮消失：模板截的是开卖前的占位按钮（如"公示中"）。它一消失就开抢。
              开卖前就能布好防，最稳，推荐。
  等按钮出现：模板截的是可购买状态（如"¥1999"）。它一出现就开抢。
              需要开卖后才有这个画面，一般不用。

匹配阈值 0.85
  画面和模板的相关度超过这个值就算命中。太低会误触发，太高会漏。
  用「当前相关度」那两个数字校准：按钮在的时候应该接近 1.0，
  不在的时候应该明显低（0.3~0.5）。如果两者差不多，说明框选区域
  里没什么可区分的东西，要重框。

左上角急停
  开着的时候，把鼠标甩到屏幕左上角 = 立刻停。抢购时手别放那儿。

点击频率 50 Hz
  实测能跑到 1400+ Hz，但游戏 UI 有自己的响应节流，50 Hz 已经足够，
  太高反而可能被判定异常。


六、校时和测速
--------------
校时：读 NTP 服务器，算出本机时钟偏差（这台机器慢约 550ms）。
      抢购按校时后的时间判断开卖时刻，所以别跳过这步。
      偏差超过 200ms 时顶部会显示黄色警告。

测速：测到腾讯服务器的 TCP 往返延迟，取最小值。
      这个数字加上时钟偏差，就是你这一下点击相对开卖时刻的总误差。


七、遇到问题
------------
「还没框选购买按钮区域」   → 框选页先把 buy / confirm 框好并存模板。
「5 秒内没看到占位按钮」   → 界面不在公示中状态，或模板截错了状态。
「鼠标被抢」               → 有别的东西在动鼠标（含你自己的手），
                            程序会立刻中止，避免点到别处。重开一次即可。
「到点了但没看到占位按钮」 → 你在开卖之后才点开始。程序会宽限 1.5 秒
                            后直接开点，但这时候已经晚了，尽量提前布防。
OCR 认不出商品名           → 商品名区域框太松，或字号太小。框紧一点。


八、文件说明
------------
start.bat      双击启动
run.py         入口
config.json    你的框选、参数、队列（自动生成，可以备份）
templates/     全局模板（buy.png / confirm.png）
data/          每条任务自己的模板
core/          程序本体（core/bricks.json 是砖皮知识库，可手改）
web/           前端页面

想从头配一遍：删掉 config.json、templates/、data/ 再启动。
